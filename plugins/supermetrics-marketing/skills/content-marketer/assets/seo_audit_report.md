# SEO audit report template

The doc summarizing the SEO content audit. Audience: content team + their marketing leadership counterpart. Often shared with the web team if technical fixes are needed.

The shape:
- Headline state of organic
- Priority action lists by classification
- Trend chart
- Sunset list (if applicable)

---

## Tone notes

- The "Update now" list is the most-actionable section and should get the most attention in the doc.
- For each decaying page, surface a specific reason if possible: "Featured snippet lost to [competitor] in [month]" tells the user what to actually fix.
- "Sunset" recommendations need clear redirect targets — sunsetting a page that has backlinks without a redirect loses the link equity.
- Length: 2-4 pages depending on number of pages requiring action.
