# Event pipeline report template

The doc reporting on pipeline created by an event's attendees over 30/60/90 day windows. Audience: VP of Sales / CRO + marketing leadership.

The shape:
- Headline (pipeline created vs cost)
- Attendee → pipeline conversion funnel
- 30/60/90 day progression
- Specific deals worth highlighting

## What's not in this number

- **Net-new contacts**: [N] attendees were not previously in our CRM. They represent pure event acquisition (vs influence on existing accounts).
- **Influence on existing accounts**: [N] attendees came from accounts already in pipeline before the event. The event may have accelerated those deals — hard to measure, but worth noting.
- **No-shows**: [N] registered but didn't attend. They've been added to nurture; future conversion isn't credited here.

---

## Tone notes

- Pipeline numbers from a single event are noisy. Surface that explicitly — one big deal can dwarf the rest.
- The "notable opportunities" list is for the sales leader. Even if anonymized externally, internal versions should name names.
- Don't claim causality. The event "produced" pipeline only in the sense that attendees became opportunities; we can't prove the event was decisive without holdout testing.
- Length: 2-3 pages.
