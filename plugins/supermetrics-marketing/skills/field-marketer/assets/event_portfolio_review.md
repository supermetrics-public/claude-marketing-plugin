# Event portfolio review template

The doc reviewing event ROI across a quarter or year. Audience: marketing leader + event ops + finance.

The shape:
- Headline (the winning event type)
- Performance by event type
- Winners and underperformers
- Recommended next-period mix

## Tone notes

- Composite scores are relative — rank-order matters more than absolute numbers.
- "Why it worked" hypotheses should be specific. "Good attendance" is not why; "tight target list of 50 accounts with 60% attendance" is.
- Recommendations to sunset events are politically charged. State the data clearly; let the conversation happen.
- Length: 3-4 pages.
