# Daily morning standup summary template

The short summary that comes out of the daily check workflow. The audience is the user themselves — this is a personal "what do I do today?" doc, not a deliverable for anyone else. Keep it scannable and action-oriented.

The shape:
- One-line headline (what's the story today?)
- "What to act on today" — specific, with the action named
- "What to watch" — early signals, not yet actionable
- One-line note on data freshness

### What to watch (not yet actionable)

- **[Channel/campaign]** — [Early signal: "Frequency creeping past 3 on top creative", "Spend up 18% on Tuesday — within normal range but worth noting"]. If it continues, [what to do].
- **[Channel/campaign]** — [Same structure.]

### Data note

[One line on data freshness if relevant. "Facebook data is near-real-time. Google Ads conversions for yesterday may still be updating over the next 48 hours."]

---

## Tone notes

- This is for the user, not for anyone else. Skip greetings, closings, and explanations.
- Action items must be specific. "Monitor performance" is not an action. "Pause ad set ABC123, lower bid on campaign DEF to $1.50" is an action.
- If nothing needs action today, say so explicitly: "Nothing needs action today — performance is within normal range." That's a valid and useful answer.
- Watch items should have a tripwire: "if frequency exceeds 4, refresh." Without the tripwire, watch items just accumulate.
- If sent via Slack to share with a teammate, drop the "headline" framing and lead with the action items. Slack readers want the verbs first.
