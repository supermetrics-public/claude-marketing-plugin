# Week-over-week optimization doc template

Use this structure for the deliverable at the end of the WoW optimization workflow. The point of this doc isn't to summarize the data — it's to tell the user what to do Monday morning. Every section should end with a concrete action, not a recommendation to "monitor."

---

# [Campaign name] — Week-over-week optimization

**Channels analyzed:** [LinkedIn Ads, Facebook Ads, etc.]

[One sentence on the overall direction: "Spend up X%, conversions down Y% — efficiency is sliding and we need to act this week."]

---

## Tone notes

- The doc should be skimmable in 90 seconds. The headline + the two tables should tell the whole story.
- Dollar amounts and ad names beat percentages and adjectives. "Save $400/week" lands harder than "improve efficiency."
- If a section is empty (e.g. no demographic effect worth noting), delete it. Empty sections make the doc feel like it's hedging.
